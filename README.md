# Recoil Rivals — Android Prototype

Original physics/recoil duel game prototype based on the supplied design brief.

## Playable prototype features
- Portrait Android app shell
- 10 stages
- Tap to fire
- Recoil is movement
- Pistol, Revolver, Shotgun
- Four enemy behaviors
- Obstacles and arena collision
- 3-heart health system
- Coins, XP, stars and local save
- Weapon unlock/select screen
- Victory/defeat/retry/next level
- Particles, generated sound effects, haptics and screen shake
- Slow-motion final hit

## Build
Open the folder in Android Studio and build the `app` module, or run the included GitHub Actions workflow.
